# Title

Pipa Image-Grounded Prototype Packet.

# Project Intent

Promote the Round 8 pipa exploration into a repo-tracked L2 packet that is
useful for review and measurement planning without claiming final CNC geometry.

# Readiness

L2 prototype scaffold. The packet supports flat silhouette mule work and CAD
iteration only.

# Fabrication Authority

`cad/v2-dxf-starter.dxf` controls prototype front-layout review geometry.

# Visual Authority

`visual-output-register.csv` marks generated concept prompts as concept-only.

# Visible Geometry

The packet preserves a front silhouette, centerline, provisional strings, and
bridge planning block as review geometry.

# Inferred Geometry

String spacing, bridge placement, and fret zones are provisional and require
reference review.

# Unresolved Geometry

Rear shell, pegbox side profile, final bridge placement, and final fret geometry
are intentionally unresolved.

# BOM

Use inexpensive sheet stock, temporary fret marks, and a bridge mockup for the
first review mule.

# Validation

Run the visual authority validator, check DXF scale in CAD, then validate
against a measured reference member.

# Risks

The main risk is turning one angled image into false precision. The packet keeps
that boundary visible.

# Next Actions

Recover or re-review the Round 8 source photo, build a flat silhouette mule,
capture reference measurements, then revise the DXF with explicit provenance.
